# Приложение Expense Tracker (Трекер расходов) на Python

Итоговая аттестационная работа по курсу. Приложение представляет собой удобный графический трекер для ведения учета личных финансов, распределения расходов по категориям, гибкой фильтрации и автоматического расчета бюджета за выбранные временные периоды.

## ✨ Ключевые возможности
* **Удобный учет:** Быстрое добавление расходов с указанием точной суммы, категории и даты.
* **Автоматическое логирование дат:** Приложение автоматически подставляет текущую дату, избавляя от ручного ввода.
* **Строгая валидация данных:**
  * Защита от ввода отрицательных или нулевых сумм, а также букв вместо чисел.
  * Проверка корректности формата дат (XXXINLINECODEXXX20XXXINLINECODEXXX) с помощью встроенного модуля XXXINLINECODEXXX21XXXINLINECODEXXX.
* **Продвинутая аналитика и фильтрация:**
  * Сортировка и фильтрация по категориям (Еда, Транспорт и т.д.).
  * Фильтрация за любой произвольный период (по датам «С» и «По»).
  * Динамический пересчет строки «Итого за период» в зависимости от активных фильтров.
* **Надежное хранение:** Сохранение структуры данных в локальный файл XXXINLINECODEXXX22XXXINLINECODEXXX.

## 🛠 Технологии
* **Python 3.x**
* **Tkinter & TTK** — графический интерфейс (использован элемент XXXINLINECODEXXX23XXXINLINECODEXXX для табличного вывода).
* **JSON** — файловая база данных.
* **Datetime** — валидация времени.
