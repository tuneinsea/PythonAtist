# Менеджер контактов на Python (Tkinter + JSON)

Итоговая аттестационная работа по курсу разработки на Python. Приложение представляет собой десктопный менеджер контактов с удобным графическим интерфейсом, локальным хранением данных и встроенной валидацией.

## ✨ Функционал программы
* **Добавление контактов** с автоматической проверкой на дубликаты имен.
* **Строгая валидация:** проверка минимальной длины имени (от 2 символов) и проверка маски телефона через регулярные выражения (XXXINLINECODEXXX12XXXINLINECODEXXX).
* **Поиск на лету:** список обновляется автоматически по мере ввода букв или цифр в окне поиска.
* **Удаление:** безопасное удаление выбранного контакта (включая режим работы в отфильтрованном поиске).
* **Постоянство данных:** автоматическое сохранение и чтение базы данных в формате XXXINLINECODEXXX13XXXINLINECODEXXX.

## 🛠 Технологический стек
* Python 3.x
* Tkinter (встроенная графическая библиотека)
* JSON (модуль для работы с файловой БД)
* Регулярные выражения (модуль XXXINLINECODEXXX14XXXINLINECODEXXX для валидации)
